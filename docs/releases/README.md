## Mantener las notas

Cada entrega mantiene Markdown y JSON junto a la versión de Cargo y sus paquetes locales en Cargo.lock. Los JSON son datos del launcher, usados por Novedades: no eliminarlos como documentación sobrante. Conservar el historial y registrar cambios nuevos en la entrega correspondiente, sin presentar validaciones pendientes como realizadas. Para publicar, seguir el [contrato del actualizador](../actualizaciones-launcher.md).
