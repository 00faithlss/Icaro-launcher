# Icaro Launcher 0.3.0

Entrega 0.3.0: canales Estable/Beta, Quilt, mejoras de capturas, Forge/NeoForge, Fabric API por defecto y corrección de apertura del inicio de sesión. main publica la estable y develop las betas.

## Cambios incorporados desde develop

- **Canal de actualizaciones Estable/Beta.** En **Ajustes → Acerca de** puedes elegir recibir también las betas, que llegan antes y pueden tener errores. El canal Estable, el predeterminado, nunca ofrece una beta. Una beta se identifica en Acerca de y en la pantalla de actualización.

## Nuevo (Quilt)

- **Quilt funciona como loader.** Crear una instancia Quilt, jugarla y cambiar su versión o la del loader usa el perfil oficial de Quilt, con Java y bibliotecas verificadas, igual que Fabric. Las versiones del loader se ordenan con las estables primero.

## Mejorado

- **Capturas abre sin congelar la interfaz.** La galería muestra miniaturas preparadas en segundo plano, que aparecen a medida que están listas, en lugar de cargar cada captura a resolución completa. El visor sigue abriendo el original.


## Nuevo y mejorado

- **Forge y NeoForge.** Instalación y preparación mediante sus instaladores oficiales, respetando la versión elegida y la configuración de Java.
- **Modpacks con versión fijada.** Los MRPACK y ZIP reconocen Forge y NeoForge y conservan la versión del loader indicada por el paquete. Los ZIP que solo referencian archivos mediante IDs siguen necesitando su integración de distribución.
- **Fabric API por defecto.** Se instala una versión compatible al preparar una nueva instancia Fabric. Se conservan copias locales o desactivadas y el contenido de modpacks; no se vuelve a añadir si lo retiras después. Si no existe una versión compatible, Fabric se conserva sin ese mod.
- **Preparación aislada.** Forge y NeoForge se preparan en una carpeta aparte y reutilizan archivos verificados. Un intento fallido conserva la instalación anterior.

## Corregido

- Corrige la apertura del inicio de sesión en Windows para utilizar cualquier navegador configurado como predeterminado del sistema.

## Validación y limitaciones

Se completaron las instalaciones oficiales de Forge para Minecraft 1.20.1 y NeoForge para 1.21.1 y 26.3, con reutilización sin red y rechazo de una biblioteca alterada. Pasó también la descarga e instalación real de Fabric API desde Modrinth.

Tras integrar los canales y Quilt, la validación local obtuvo 245 pruebas aprobadas del núcleo, 125 de interfaz/launcher y 2 del actualizador. La prueba de recuperación desde la papelera de Windows había fallado antes de la integración y se bloqueó al repetirla; se interrumpió esa ejecución y se verificó el resto excluyéndola. Su código no se modificó. Estos resultados no sustituyen el CI remoto.

Quedan pendientes la validación manual del inicio de sesión con distintos navegadores, las partidas con mods, migraciones, cancelación/recuperación durante los procesadores y el recorrido nativo en Linux. No se admiten todos los formatos históricos de Forge; falta validar Quilt en una partida real. La preparación de un cliente no acredita una partida.

Consulta el [alcance técnico y almacenamiento](../loaders-forge-neoforge.md).
